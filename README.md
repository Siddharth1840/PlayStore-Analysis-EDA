📱 Google Play Store App Analytics — Exploratory Data Analysis    ➡ 

————————————————————————————————————————————————————

📊 Project Overview

————————————————————————————————————————————————————

This project performs an in-depth exploratory data analysis (EDA) on a dataset of 10,800+ mobile applications from the Google Play Store. The goal is to identify key factors influencing app success — including ratings, installs, pricing, category, and app size — and translate these findings into actionable business recommendations for app developers and marketers.

————————————————————————————————————————————————————

❓ Problem Statement

————————————————————————————————————————————————————

The dataset contains detailed information on mobile apps but lacks clear insight into what drives high performance. This project analyzes patterns across categories, pricing models, and user engagement metrics to help businesses make data-driven decisions on app strategy.

————————————————————————————————————————————————————

✨ Key Features

————————————————————————————————————————————————————

➡  Cleaned and preprocessed raw data (handled missing values, fixed mixed-format columns like Size, Installs, Price)

➡  Converted non-numeric fields into proper numeric types for analysis

➡  Engineered new features (Year, Month) from date fields

➡  Built 15+ visualizations to explore relationships between variables

➡  Generated a correlation heatmap and pair plot for multivariate analysis

➡  Delivered business recommendations based on data insights

————————————————————————————————————————————————————

🔍 Key Insights

————————————————————————————————————————————————————

➡ Free apps dominate the market (90%+ of total apps)

➡ Apps rated below 3.0 show minimal install growth

➡ Strong positive correlation (>0.6) between Reviews and Installs

➡ Games, Tools, and Family categories have the highest competition

➡ Larger apps (100MB+) tend to see fewer 5-star ratings
